RIDELAB — IPHONE 13 OFFLINE EDITION
==================================

WHAT YOU GET
- The original snowboard training website, exercises and images.
- Larger tap targets and a fixed bottom navigation bar on iPhone.
- Working week/day selectors, technique information, checkboxes, session tracker,
  library search, progress export, and rest timer.
- Offline-capable iPhone Home Screen app (PWA).
- Local workout progress (stored on the phone, not synced to a cloud).
- No external font downloads are required.

INSTALL ON YOUR IPHONE 13
1. Upload the CONTENTS of this folder to any HTTPS static hosting service
   (for example Netlify Drop, Cloudflare Pages, or GitHub Pages).
   The website URL must be HTTPS. Simply opening the files as a ZIP in Files
   does NOT install a reliable iOS offline web app.
2. On your iPhone, open the deployed HTTPS URL in SAFARI.
3. Keep the page open with internet briefly so its 8 exercise-image sheets
   are cached. The first install downloads approximately 15 MB.
4. Tap the Share button, choose Add to Home Screen, then tap Add.
5. Launch RIDELAB from the new Home Screen icon.
6. After the initial load completes, try Airplane Mode and open it again.
   All in-app workouts, images, navigation and tracking should work offline.

NOTES
- Outside links to research/publications need internet.
- Progress saves in local iOS website storage. Do not delete website data
  or uninstall the app if you need to keep your progress.
- Use Export progress before changing devices; the exported JSON is a backup,
  but importing it is not yet supported.
- The rest timer stays accurate across screen lock/background while the app is
  retained, but iOS does not guarantee audible notifications in the background.
- On iOS, Safari may purge cached content under extreme storage pressure.
- Hosting is required only for the initial install and future updates;
  the app itself can be used offline after caching.
